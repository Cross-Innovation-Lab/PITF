# Third-party code

- [ConFEDE](https://github.com/XpastaX/ConFEDE), commit `640d8831b6c8befe2a438fe59671caee25ec4edd`. The bundled code retains its [MIT license](third_party/ConFEDE/LICENSE). The local adapter sets the dataset dimensions and BERT path.
- [Multimodal Transformer](https://github.com/yaohungt/Multimodal-Transformer), commit `a670936824ee722c8494fd98d204977a1d663c7a`. The bundled code retains its [MIT license](third_party/Multimodal-Transformer/LICENSE).

MulT credits [fairseq](https://github.com/pytorch/fairseq) as the source adapted in its position embedding and multi-head attention modules.

The ConFEDE SIMS pair-selection helpers `get_all_pairs_indices` and `convert_to_pairs` credit an earlier version of pytorch-metric-learning.

The dataset and pretrained BERT files are distributed by their respective providers.
